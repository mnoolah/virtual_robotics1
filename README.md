# الروبوت التفاعلي — virtual_robotics1

مجسم روبوت ثلاثي الأبعاد تفاعلي يعرض أجزاءه الرئيسية (وحدة التحكم، المستشعرات،
الذراع الآلي، المفاصل المحركة، وحدة الطاقة، القاعدة المتحركة) مع شرح لوظيفة كل
جزء عند الضغط عليه.

مبني بنفس أسلوب لوحات التشريح التفاعلية: مجسم ثلاثي الأبعاد دوّار في الخلفية،
بطاقات نصية عائمة موصولة بخطوط منحنية ملوّنة، ولوحة تفاصيل تنبثق عند اختيار أي
جزء.

## التقنيات

- React + TypeScript + Vite
- Tailwind CSS
- `@react-three/fiber` / `@react-three/drei` / `@react-three/postprocessing` (Three.js)

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## سمفونية الحبّار

صفحة مستقلة في `public/squid-symphony.html` (تُفتح على `/squid-symphony.html` مع `npm run dev`).
تبدأ بفيديو حبّار مشرّح يسبح (`public/squid-swim.mp4`)؛ الضغط عليه يوقفه على لقطة ثابتة
تظهر فوقها تسعة عشر نقطة للأجزاء الخارجية والداخلية، مع تكبير على الجزء المختار وبطاقة شرح.
يبقى المجسم ثلاثي الأبعاد متاحًا (تشريح / خارجي / شفاف). الصوت هو صوت البحر من الفيديو نفسه
(`public/squid-sea.m4a`) مع نغمات خفيفة.
