# قلب الإنسان — تشريح تفاعلي ثلاثي الأبعاد

مجسم ثلاثي الأبعاد لقلب الإنسان ينبض باستمرار (بمعدّل ٧٢ نبضة/دقيقة)، ويعرض
حجراته الأربع وصماماته وأوعيته الكبرى مع شرح لوظيفة كل جزء عند الضغط عليه.

مبني بأسلوب لوحات التشريح التفاعلية: مجسم ثلاثي الأبعاد دوّار في الخلفية،
بطاقات نصية عائمة موصولة بخطوط منحنية ملوّنة (أحمر للجانب المؤكسج، أزرق
للجانب غير المؤكسج، وذهبي للصمامات)، ولوحة تفاصيل تنبثق عند اختيار أي جزء.

## المزايا التفاعلية

- **نبض حقيقي**: القلب ينبض بحركة "لَب-دَب" مطابقة لدورة القلب الفعلية.
- **صوت نبض القلب**: مُصنَّع بالكامل عبر Web Audio API (بدون ملفات صوتية)
  ومتزامن مع حركة النبض المرئية.
- **موسيقى خفيفة**: مقطوعة هادئة مُركَّبة من نغمات ناعمة، قابلة للتشغيل
  والإيقاف بشكل مستقل عن صوت النبض.
- **تحريك حر**: اسحب لتدوير القلب من أي زاوية، وقرّب/ابعّد بعجلة الفأرة، مع
  تدوير تلقائي عند عدم التفاعل.
- **معلومات تعليمية**: الضغط على أي حجرة أو صمام أو وعاء دموي يعرض شرحًا
  دقيقًا لوظيفته ضمن الدورة الدموية.

## التقنيات

- React + TypeScript + Vite
- Tailwind CSS
- `@react-three/fiber` / `@react-three/drei` / `@react-three/postprocessing` (Three.js)
- Web Audio API لتوليد صوت النبض والموسيقى الخلفية
